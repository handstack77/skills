# Changesets

안녕하세요, 환영합니다! 이 폴더는 `@changesets/cli`가 자동으로 생성했습니다. 다중 패키지 저장소와
단일 패키지 저장소에서 코드의 버전을 관리하고 배포하도록 돕는 빌드 도구입니다.
전체 문서는 [저장소](https://github.com/changesets/changesets)에서 볼 수 있습니다.

이 프로젝트에 참여하기 시작하는 데 도움이 되도록 자주 묻는 질문 목록을
[문서](https://github.com/changesets/changesets/blob/main/docs/common-questions.md)에 정리해 두었습니다.
