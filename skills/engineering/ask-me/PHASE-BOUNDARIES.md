# 단계 경계

**단계(phase)**는 세션 안의 작업 덩어리입니다. 집요한 질문, 구현, QA 같은 것입니다. 정의는 일부러 모호합니다. *"좋아, 이건 끝났어"* 하고 생각할 때 단계가 끝납니다.

**단계 경계**는 두 단계 사이의 틈이며, 이 결정이 속하는 유일한 곳입니다. 단계 도중에는 내릴 결정이 없습니다. 계속하거나, 남은 작업을 서브에이전트로 쪼개세요. 단계 도중에 압축하면 에이전트가 맥락을 놓칩니다.

## 다섯 가지 선택지

| 선택지       | 하는 일                                                          |
| ------------ | --------------------------------------------------------------- |
| **계속** | 세션에 머뭅니다. 컨텍스트 전환이 전혀 없습니다.                      |
| **`/clear`** | 컨텍스트 창을 비우고 아무것도 없는 상태에서 시작합니다.              |
| **`/handoff`** | 이식 가능한 마크다운 파일을 쓰고 그것으로 어디서든 세션을 시작합니다. |
| **서브에이전트** | 작업을 자기 컨텍스트 창으로 보내고 보고를 받습니다.              |
| **`/compact`** | 이 컨텍스트를 압축하고 그 요약으로 새 세션을 시작합니다.          |

## 트리

경계에서 위에서 아래로 진행하세요. 처음 나오는 **예**가 이깁니다.

**1. 이 세션에서 계속할 수 있나요?** 두 가지가 답을 예로 만듭니다. 다음 단계가 이 단계를 **1차 자료**로 필요로 하거나, 다음 단계가 들어갈 만큼 [스마트 존](../../../assets/smart-zone.md)(약 150k 토큰)이 충분히 남아 있을 때입니다. 집요한 질문 → 구현이 표준적인 예입니다. 구현은 추론을 요약이 아니라 그대로 원합니다. 계속은 비용도 없고 잃는 것도 없으므로, 다른 무엇보다 먼저 배제하세요.

**2. 컨텍스트가 다음에 올 일과 무관한가요?** 이 세션의 모든 것(탐색, 결정, 막다른 길)을 버려도 되나요? 그렇다면 **`/clear`**입니다. 판에서 가장 싼 수입니다. 시간이 들지 않고 창 전체를 돌려줍니다. `/clear`도 끝이 아닙니다. 이전 세션은 재개할 수 있습니다.

이를 잘못 판단했을 때의 비용은 일방향입니다. *관련 있는* 컨텍스트를 비우면 만든 것의 **이유**를 잃고, diff를 아무리 다시 읽어도 돌려받을 수 없습니다.

**3. 인계해야 하나요?** `/handoff`는 좁습니다. 다음의 경우에만 필요합니다.

- **새 하니스**로 바꿀 때 (Claude → Codex),
- **새 디렉터리**나 저장소로 옮길 때,
- 작업을 **동료**에게 보낼 때,
- 또는 하던 일을 방해하지 않으면서 **단계 도중**에 발견한 곁가지 작업을 포크할 때.

이 목록이 조항 전부입니다. `/handoff`가 사 주는 것은 **이식성**, 곧 돌아다닐 수 있는 파일입니다. 아무것도 옮겨 가지 않는다면 필요 없습니다.

**4. 작업을 AFK로 할 수 있나요?** 키보드에서 떠나 있어도, 조종 없이 실행할 만큼 범위가 좁게 잡혀 있나요? 그렇다면 **서브에이전트**에 보내고 이 세션은 건드리지 마세요. 자동 리뷰가 표준적인 경우입니다. 에이전트가 diff를 읽고 보고하며, 그동안 당신은 필요 없습니다.

**5. 그렇지 않다면 `/compact`.** 관련 있는 컨텍스트, 같은 하니스, 같은 디렉터리이고 계속 루프에 있어야 합니다. 트리가 도착하는 곳이 여기이며 자주 여기에 도착합니다. 지시(`/compact we're going to QA this area`)를 함께 줘서 다음 단계에 필요한 것을 요약이 보존하게 하세요.

`/compact`는 **기본값이지 첫 번째로 손이 가는 것이 아닙니다**. 그 위의 네 질문이 모두 더 싸거나 더 정밀하기 때문에 맨 아래에 있습니다. 여기서 시작할 때의 실패 양상은, 요약이 납작하게 만든 결정에 대해 자신 있게 틀린 새 세션입니다.

## 1차 자료와 2차 자료

**계속**을 제외한 모든 수는 **1차 자료**를 **2차 자료**로 바꿉니다. 일어난 그대로의 세션이 그것의 요약으로 대체됩니다. 교환은 항상 같은 모양입니다.

| 자료                              | 정보 | 잡음 | 움직일 여지 |
| --------------------------------- | ---- | ---- | ---------- |
| 1차 (계속)                         | 전체 | 많음 | 적음       |
| 2차 (`/compact`, `/handoff`)      | 손실 | 적음 | 많음       |

그래서 질문 1이 먼저입니다. 머무는 것이 아끼는 것보다 더 많이 들 때만 손실의 대가를 치르세요.

## 이것은 판단이 필요한 사안입니다

질문은 객관적이지 않습니다. 각각에 취향이 들어 있고, 같은 경계도 날에 따라 두 가지로 갈릴 수 있습니다. 가치는 작업 한가운데가 아니라 경계에서 **순서대로** 묻는 데 있습니다.
