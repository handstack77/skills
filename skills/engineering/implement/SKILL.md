> CLI별 스킬 로드: 아래의 `Skill 도구` 지시는 Claude Code에서 해당 도구로 실행합니다. Codex CLI에서는 스킬 이름으로 로컬 `SKILL.md`를 찾아 읽고 같은 절차를 따릅니다. 플러그인 설치에서는 같은 플러그인의 대상 스킬 이름에 `junchul-skills:` 접두사를 붙입니다. 사용자 호출형 스킬은 사용자의 명시적 요청이 있어야 실행합니다.

사용자가 명세나 티켓에 설명한 작업을 구현하세요.

사용자가 티켓 참조를 전달하면 이슈 트래커에서 가져와 시작하기 전에 제목을 먼저 말하세요. 참조가 모호하면 되물으세요.

가능하면 사전에 합의한 이음매(seam)에서 Skill 도구로 "tdd"를 호출하세요.

타입 검사는 자주, 단일 테스트 파일 실행도 자주 하고, 전체 테스트 스위트는 마지막에 한 번만 실행하세요.

작업이 끝나면 Skill 도구로 "code-review"를 호출해 작업물을 검토하세요.

작업 내용을 현재 브랜치에 커밋하세요.
