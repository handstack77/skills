# 기타

계속 갖고 있지만 거의 쓰지 않는 도구들이며, 기본 플러그인 설치 대상에서 제외합니다.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**: 위험한 git 명령(push, reset --hard, clean 등)이 실행되기 전에 차단하는 Claude Code 훅을 설정합니다.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**: 테스트 파일을 `as` 타입 단언에서 @total-typescript/shoehorn으로 마이그레이션합니다.
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**: 섹션, 문제, 풀이, 설명으로 이루어진 실습 디렉터리 구조를 만듭니다.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**: lint-staged, Prettier, 타입 검사, 테스트를 실행하는 Husky pre-commit 훅을 설정합니다.
