> CLI별 스킬 로드: 아래의 `Skill 도구` 지시는 Claude Code에서 해당 도구로 실행합니다. Codex CLI에서는 스킬 이름으로 로컬 `SKILL.md`를 찾아 읽고 같은 절차를 따릅니다. 플러그인 설치에서는 같은 플러그인의 대상 스킬 이름에 `junchul-skills:` 접두사를 붙입니다. 사용자 호출형 스킬은 사용자의 명시적 요청이 있어야 실행합니다.

새 에이전트가 작업을 이어갈 수 있도록 현재 대화를 요약한 인수인계 문서를 작성하세요. 저장 위치는 현재 작업 공간이 아니라 사용자 OS의 임시 디렉터리입니다(`$TMPDIR`, 없으면 `/tmp`, Windows에서는 `%TEMP%`).

문서에 "추천 스킬" 섹션을 넣어, 다음 에이전트가 Skill 도구로 호출해야 할 스킬을 명시하세요.

다른 산출물(명세, 계획, ADR, 이슈, 커밋, diff)에 이미 담긴 내용은 중복해서 쓰지 마세요. 경로나 URL로 참조하세요.

API 키, 비밀번호, 개인 식별 정보 같은 민감한 정보는 가리세요.

사용자가 인자를 전달했다면 다음 세션이 집중할 내용에 대한 설명으로 보고, 그에 맞춰 문서를 조정하세요.
