# GLOSSARY.md 형식

`GLOSSARY.md`는 이 교육 작업 공간의 표준 언어입니다. 모든 설명, 연습, 학습 기록은 그 용어를 지켜야 합니다. 용어집을 만드는 것 자체가 학습의 일부입니다. 개념을 간결한 정의로 압축하는 것은 사용자가 그것을 이해한다는 증거입니다.

## 구조

```md
# {Topic} Glossary

{이 용어집이 다루는 주제에 대한 한두 문장 설명.}

## Terms

**Hypertrophy**:
반복되는 훈련 세션에 걸친 기계적 긴장과 대사 스트레스로 유발되는 근육 성장.
_Avoid_: Bulking, getting big

**Progressive overload**:
부하, 볼륨, 강도를 통해 시간이 지남에 따라 근육에 대한 요구를 체계적으로 늘리는 것.
_Avoid_: Pushing harder, levelling up

**RPE (Rate of Perceived Exertion)**:
한 세트가 얼마나 힘들었는지에 대한 1~10점 자체 평가로, 10은 실패이고 8은 두 번 더 할 여력이 남았다는 뜻.
_Avoid_: Effort score, intensity rating
```

## 규칙

- **사용자가 이해한 용어만 추가하세요.** 용어집은 압축된 지식의 기록이지, 사용자가 배우려고 읽는 사전이 아닙니다. 사용자가 방금 개념을 소개받았다면, 올바르게 쓸 수 있게 될 때까지 기다렸다가 여기에 올리세요.
- **단호하게 정하세요.** 같은 개념에 단어가 여러 개 있으면 가장 좋은 것을 하나 고르고 나머지는 피해야 할 별칭으로 나열하세요. 이렇게 언어가 압축됩니다.
- **정의를 간결하게 유지하세요.** 한두 문장입니다. 용어가 무엇을 하는지나 어떻게 하는지가 아니라 무엇*인지*를 정의하세요.
- **정의 안에서 용어집 자체의 용어를 사용하세요.** 용어가 용어집에 들어가면, 다른 정의 안을 포함해 어디서나 그것을 선호하세요. 이것이 복잡한 용어를 나중에 더 쉽게 파악하게 합니다.
- **자연스러운 묶음이 생기면 소제목으로 묶으세요** (예: `## Anatomy`, `## Programming`). 용어들이 응집되어 있다면 평평한 목록도 괜찮습니다.
- **모호성을 명시적으로 표시하세요.** 용어가 더 넓은 분야에서 느슨하게 쓰인다면 해소 방식을 적으세요. "이 작업 공간에서 'set'은 항상 워킹 세트를 뜻한다. 워밍업은 따로 추적한다."
- **이해가 깊어지면 고치세요.** 사용자가 첫 주에 쓴 정의가 여섯 주째에는 틀릴 수 있습니다. 제자리에서 갱신하고 낡은 항목을 남기지 마세요.
