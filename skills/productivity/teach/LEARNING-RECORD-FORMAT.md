# 학습 기록 형식

학습 기록은 `./learning-records/`에 두며 순번을 매깁니다. `0001-slug.md`, `0002-slug.md` 같은 식입니다. 디렉터리는 필요할 때 만드세요. 첫 기록을 쓸 때만 만듭니다.

학습 기록은 ADR의 교육판입니다. 뻔하지 않은 교훈, 핵심 통찰, 밝혀진 사전 지식을 담아 이후 세션을 이끕니다. 근접 발달 영역을 계산하는 데 쓰입니다.

## 템플릿

```md
# {배운 것 또는 확립된 것의 짧은 제목}

{1~3문장: 무엇을 배웠는지(또는 어떤 사전 지식이 확립되었는지), 그리고 이후 세션에 왜 중요한지.}
```

이것이 형식의 전부입니다. 학습 기록은 한 문단일 수 있습니다. 가치는 섹션을 채우는 데 있지 않고, 이것이 이제 알려져 있다는 _사실_과 그것이 다음에 가르칠 것을 _왜_ 바꾸는지를 기록하는 데 있습니다.

## 선택 섹션

진짜 가치를 더할 때만 넣으세요. 대부분의 기록에는 필요 없습니다.

- **Status** frontmatter (`active | superseded by LR-NNNN`): 이전의 이해가 틀렸다고 드러나 대체될 때 유용
- **Evidence**: 사용자가 이해를 어떻게 입증했는지(답한 질문, 마친 연습, 언급한 사전 경험). 주장을 다시 살펴볼 수 있을 때 유용
- **Implications**: 이것이 이후 세션에 무엇을 열고 무엇을 배제하는지. 뻔하지 않을 때 기록할 가치가 있음

## 번호 매기기

`./learning-records/`에서 가장 큰 기존 번호를 찾아 1을 더하세요.

## 학습 기록을 쓸 때

다음 중 하나라도 참일 때 쓰세요.

1. **사용자가 사소하지 않은 것에 대한 진짜 이해를 입증했다**: 단순한 노출이 아니라 개념을 올바르게 쓸 수 있다는 증거. 이것이 다음에 가르칠 것의 새로운 하한선을 정합니다.
2. **사용자가 사전 지식을 밝혔다**: "나는 이미 X를 안다." 이후 세션이 다시 가르치지 않도록 기록하세요. 주장한 _깊이_도 기록하세요.
3. **오해가 바로잡혔다**: 사용자가 이전에 틀린 것을 믿었고 이제 이유를 이해했습니다. 가치가 높습니다. 관련 주제에서 앞으로 걸려 넘어질 곳을 예측해 줍니다.
4. **학습에 반응해 미션이 바뀌었다**: 사용자가 생각했던 것과 다른 것에 관심이 있음을 발견했습니다. [[MISSION.md]]에 교차 링크하고 갱신하세요.

### 해당하지 _않는_ 것

- 그저 다룬 자료. 다룬 것은 학습이 아닙니다. 증거를 기다리세요.
- 이미 [[GLOSSARY.md]]에 용어 정의로 간결하게 담긴 모든 것. 중복하지 마세요.
- 세션별 활동 로그. 학습 기록은 일지가 아니라 결정 수준의 통찰입니다.

## 대체

이후 기록이 이전 기록과 모순될 때(사용자의 이해가 깊어지거나 바로잡혔을 때)는 이전 기록을 삭제하지 말고 `Status: superseded by LR-NNNN`으로 표시하세요. 이해가 어떻게 진화했는지의 이력 자체가 유용한 신호입니다.
