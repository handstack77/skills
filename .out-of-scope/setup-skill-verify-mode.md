# `setup-me-skills`의 검증/확인 모드

이 프로젝트는 `setup-me-skills`를 위한 전용 검증/확인 모드(또는 별도의 검증 스킬)를 추가하지 않습니다.

## 범위 밖인 이유

`docs/agents/*.md` 산출물이 시드 템플릿 스키마와 여전히 일치하는지 확인하는 두 번째 스킬(또는 `--verify` 플래그)은, 기존 설정 스킬이 이미 대화로 처리하는 작업을 중복하게 됩니다.

의도된 워크플로는 이렇습니다. **`/setup-me-skills`를 실행하고 현재 설정을 검증하라고 말하세요.** 스킬은 프롬프트 주도이므로, 메인테이너는 별도의 코드 경로 없이 검증 패스로 범위를 한정할 수 있습니다("아무것도 다시 쓰지 말고, 기존 파일이 현재의 시드 템플릿과 어긋나는지만 확인해서 보고해"). 플래그나 형제 스킬을 추가하면 이미 자연어 진입점으로 표현할 수 있는 기능의 표면적이 쪼개집니다.

설정 관리를 하나의 스킬에 두면 시드 템플릿이 진화할 때 두 스킬이 서로 어긋나는 유지보수 비용도 피할 수 있습니다.
