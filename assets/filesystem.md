# 파일 시스템 (Filesystem)

> 도구와 환경

에이전트가 읽고, 쓰고, 실행하는 파일과 디렉터리의 트리. 코딩 에이전트의 기본 환경입니다.

[에이전트](./agent.md)가 읽고, 쓰고, 안에서 실행하는 파일과 디렉터리의 트리로, 코딩 에이전트의 기본적인 [환경](./environment.md) 종류입니다. [AGENTS.md](./agents-md.md), [스킬](./skill.md), 소스 코드, 빌드 스크립트, [도구](./tool.md) 설정이 모두 파일 시스템에 있습니다. [하니스](./harness.md)가 "프로젝트에서 시작한다"는 것은 에이전트를 파일 시스템에 향하게 한다는 뜻입니다.

에이전트는 [도구 호출](./tool-call.md)로만 파일 시스템에 닿습니다. 파일을 읽고, 쓰고, 셸 명령을 실행합니다. 디스크의 어떤 것도 도구 호출이 로드하기 전에는 [컨텍스트 창](./context-window.md)에 없으며, 이 덕분에 에이전트가 창보다 훨씬 큰 저장소에서 일할 수 있습니다. 파일 시스템이 모든 것을 담고 컨텍스트에는 현재 작업이 읽은 것만 들어 있습니다. 일부 하니스는 기본적으로 현재 디렉터리의 파일 이름을 컨텍스트 창에 로드하기도 합니다. 내용이 아니라 트리만이며, 이것이 [컨텍스트 포인터](./context-pointer.md)로 작용합니다. 에이전트는 무엇이 있는지 보고 필요한 파일을 읽습니다.

그리고 당신과 공유됩니다. 에이전트가 편집하는 파일은 당신이 에디터에서 열고 git으로 diff를 보는 바로 그 파일입니다. 파일 시스템은 에이전트가 한 일을 검토하는 공동 작업 공간입니다.

_사용 예:_

"왜 제 AGENTS.md를 못 읽죠?"

"다른 파일 시스템에서 실행되고 있어요. [샌드박스](./sandbox.md)가 프로젝트 루트가 아니라 상위 디렉터리를 마운트했습니다. 하니스가 가리키는 곳을 다시 지정하세요."
