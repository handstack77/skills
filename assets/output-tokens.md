# 출력 토큰 (Output tokens)

> 모델

모델이 생성해 돌려주는 토큰. 만드는 데 연산이 더 들어서 입력 토큰보다 높은 요율로 과금됩니다.

[모델](./model.md)이 생성해 돌려주는 [토큰](./token.md)입니다. 만드는 데 연산이 더 들어서 [입력 토큰](./input-tokens.md)보다 높은 요율, 흔히 약 다섯 배로 과금됩니다.

모델이 쓰는 모든 것이 셈에 들어갑니다. 당신이 읽는 산문, 내놓는 코드, [도구 호출](./tool-call.md), 답하기 전에 모델이 하는 확장된 사고. 마지막 것이 사람들을 놀라게 합니다. 추론 토큰은 [하니스](./harness.md)가 흔히 보여 주지 않아도 출력으로 과금되며, [추론 노력](./effort.md)을 올리면 더 많이 씁니다.

출력 토큰은 [세션](./session.md)의 속도도 정합니다. 모델은 입력은 빠르게 읽지만 출력은 한 번에 토큰 하나씩 생성하므로, [턴](./turn.md)이 느리게 느껴질 때는 거의 항상 입력을 읽는 것이 아니라 출력이 쓰이는 중입니다. 오래 기다린다면 보통 긴 답이 오고 있다는 뜻입니다.

_사용 예:_

"입력은 작은데도 리팩터링 세션이 크레딧을 태워요."

"에이전트가 패치하는 대신 파일 전체를 다시 쓰고 있어요. 출력 토큰은 입력 요율의 대략 다섯 배예요. 편집만 내보내게 하면 청구서가 줄어요."
