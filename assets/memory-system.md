# 기억 시스템 (Memory system)

> 기억과 조향

환경에 저장하고 세션 시작 때 다시 로드해서 에이전트가 세션을 넘어 상태를 갖게 하려는 시스템.

[에이전트](./agent.md)가 [세션](./session.md)을 넘어 [상태를 갖게](./stateful.md) 하려는 시스템입니다. 세션 중에 정보를 [환경](./environment.md)에 저장하고 이후 세션 시작 때 [컨텍스트 창](./context-window.md)에 다시 로드하므로, 사용자가 세션을 [비운](./clearing.md) 뒤에도 에이전트가 연속성을 이어 갑니다.

기억 시스템에는 두 반쪽이 있습니다. 쓰기 경로: 세션 중에 에이전트가 배운 것, 곧 당신이 밝힌 선호나 프로젝트에 대한 사실을 환경의 파일로 기록합니다. 읽기 경로: 세션 시작 때 [하니스](./harness.md)가 그 파일이나 그 색인을 컨텍스트 창에 다시 로드합니다. 많은 하니스가 자체 기억 시스템을 제공하며(Claude Code의 `/memory`가 그중 하나), 직접 만들 수도 있습니다. 메모 디렉터리와, 그것을 참고하라는 [AGENTS.md](./agents-md.md)의 지침이면 됩니다.

항상 로드되는 내용에 적용되는 것과 같은 트레이드오프가 여기에도 적용됩니다. 기억은 쌓이므로, 대부분의 시스템은 한 줄짜리 색인을 로드하고 본문은 모두 인라인으로 넣는 대신 [컨텍스트 포인터](./context-pointer.md) 뒤에 둡니다. 또 기억은 [2차 자료](./secondary-source.md)이므로 어긋납니다. 3월에 기록된 사실이 프로젝트가 달라진 6월에도 같은 확신으로 로드됩니다. 기억 시스템도 AGENTS.md처럼 가지치기가 필요합니다.

_사용 예:_

"제가 MySQL이 아니라 Postgres를 쓴다고 계속 다시 말해야 해요."

"기억 시스템을 연결하세요. 첫 [턴](./turn.md)에 배운 것을 [파일 시스템](./filesystem.md)에 쓰고, 세션 시작 때 다시 로드하게요. [모델](./model.md) 자체는 [상태가 없고](./stateless.md), 기억 계층이 연속성을 흉내 냅니다."
